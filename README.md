# Architecture-Studio

## Contenu

- **Tracé — Éditeur (Version 2).html** : Éditeur de parcours et de flowcharts interactif (Version 2).
  - Support FR/EN
  - Export PNG / PDF
  - Nœuds, décisions, post-its, images, icônes
  - Sauvegarde locale (localStorage) + import/export JSON

- **icones/** : Collection d'icônes classées par famille (Bootstrap Icons, Lucide, Tabler Icons).
  - Voir `icones/LISEZ-MOI.txt` et `icones/INDEX.csv` pour le détail.
  - **Note** : le fichier ZIP complet (`icones_familles.zip`) contient ~10 364 fichiers SVG.  
    Il n'a pas été décompressé dans le dépôt car trop volumineux pour un push API unique.  
    Tu peux le télécharger et le décompresser localement, ou le déposer via l'interface GitHub (Upload files).

## Utilisation rapide de l'éditeur

Ouvre simplement le fichier HTML dans un navigateur moderne.
